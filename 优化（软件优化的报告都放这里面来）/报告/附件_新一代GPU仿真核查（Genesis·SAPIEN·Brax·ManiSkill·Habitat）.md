## 软件名：Genesis（Genesis World 1.4.1，2026 年）
- **一句话定位**：把「统一多物理引擎（刚体/FEM/MPM/PBD/SPH/烟雾/IPC）+ 自研光追渲染器 Nyx + 跨平台编译器 Quadrants」放在一个 Pythonic API 后的物理 AI 仿真平台，从笔记本 CPU 一路扩到数据中心 GPU（[官方 Introduction](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/what_is_genesis.html)、[PyPI 1.4.1](https://pypi.org/project/genesis-world/)）。
- **许可证 / 闭源商用**：Apache 2.0，允许闭源商用（[PyPI License 段](https://pypi.org/project/genesis-world/)）。注意 Nyx 渲染器是独立的 `gs-nyx` 包，当前「通过内部包索引分发，尚未上 PyPI」（[Nyx renderer 页](https://genesis-world.readthedocs.io/en/latest/user_guide/rendering/nyx_renderer.html)），其许可条款需单独核对：**未查证**。
- **支持平台（含 macOS）**：Linux / Windows / macOS；后端 CUDA、AMD ROCm、Apple Metal（`gs.metal`）、CPU。官方支持矩阵明确 macOS + Apple Silicon 的 **GPU 仿真 ✅ / CPU 仿真 ✅ / 交互查看器 ✅ / 无头渲染 ✅**。`gs.gpu` 解析顺序为 CUDA → AMD → Metal → CPU；Intel GPU 只能驱动查看器与离屏渲染，无仿真后端（[Installation](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/installation.html)、[Initialization and backends](https://genesis-world.readthedocs.io/en/latest/user_guide/configuration/initialization.html)）。**对 Apple M5 macOS 是本报告五者中最正面的一个。**
- **A 物理引擎**：不基于 PhysX/Bullet/MuJoCo，而是自研统一多物理引擎，由 [Quadrants](https://github.com/Genesis-Embodied-AI/quadrants) 编译器（2025 年 6 月从 Taichi fork）下推到 CUDA / AMD ROCm / Apple Metal / Vulkan / x86 / ARM64。求解器族：Rigid、FEM、MPM、PBD、SPH、Stable Fluid（烟雾）、IPC（libuipc 后端）、以及 SAP 耦合器与显式耦合器，全部共享「一个场景、一个状态」（[Introduction](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/what_is_genesis.html)、[Beyond rigid bodies](https://genesis-world.readthedocs.io/en/latest/user_guide/physics/beyond_rigid_bodies.html)）。刚体接触模型：软约束（soft constraint）公式，Jacobian + 参考加速度 + 刚度对角阵；摩擦锥可选**金字塔锥（默认）**或**椭圆锥**，接触求解可选 **`convex`（MuJoCo 公式）**或 **`signorini`（需椭圆锥 + Newton 求解器）**；支持扭转摩擦 `enable_torsional_friction` 与滚动摩擦 `enable_rolling_friction`；约束求解器可选 **Newton（默认，Cholesky，CPU 可用稀疏带状分解）**或 **CG（预条件共轭梯度）**；`iterations`/`tolerance`/`ls_iterations`/`ls_tolerance` 可调（[Constraint model](https://genesis-world.readthedocs.io/en/latest/user_guide/theory/rigid_solver/constraints.html)）。软体/可形变/流体：MPM（Elastic/Liquid/ElastoPlastic/Sand/Snow/Muscle）、FEM（Elastic/Cloth/Muscle，暴露杨氏模量 E 与泊松比 nu）、PBD（Cloth/Elastic/Liquid/Particle）、SPH（Liquid，参数 rho/mu/gamma）、Stable Fluid（烟雾，Eulerian 网格 + Jacobi 压力投影）（[Beyond rigid bodies](https://genesis-world.readthedocs.io/en/latest/user_guide/physics/beyond_rigid_bodies.html)）。GPU 并行规模：官方称单 GPU 支持「tens of thousands of environments」，`scene.build(n_envs=B)` 一次 `scene.step()` 推进整批（[Parallel simulation](https://genesis-world.readthedocs.io/en/latest/user_guide/getting_started/parallel_simulation.html)）；吞吐的官方量化声明为「相对 Isaac Gym/Sim/Lab 与 MuJoCo MJX 最高 10–80×，且不牺牲精度」（[Introduction](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/what_is_genesis.html)，方法论在官方博客 [genesis.ai blog](https://www.genesis.ai/blog/the-role-of-simulation-in-scalable-robotics-genesis-world-10-and-the-path-forward)）。
- **B 传感器**：`gs.sensors` 家族齐全——**IMU**（lin_acc / ang_vel / mag；可配 `*_noise`、`*_bias`、`*_random_walk`、`*_cross_axis_coupling`、`*_resolution`，以及共享 `delay` / `jitter`；加速计输出的是比力，静止读数约 (0,0,9.81)）（[IMU](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/imu.html)）；**Contact / ContactForce / JointTorque**；**触觉**（ContactProbe、ContactDepthProbe、KinematicTaxel、ElastomerTaxel、ProximityTaxel）；**Raycaster**：`Lidar`（SphericalPattern 球扫 / GridPattern 平面平行光）与 `DepthCamera`（DepthCameraPattern 针孔），支持自定义 RaycastPattern；**相机**：RasterizerCameraOptions / RaytracerCameraOptions / BatchRendererCameraOptions；**SurfaceDistanceProbe**；**TemperatureGrid**（[Sensors 总览](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/index.html)、[Raycaster sensors](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/raycaster.html)、[Camera sensors](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/camera_sensors.html)）。语义分割：相机传感器 `read()` **只返回 RGB**，分割/深度/表面法线要走 visualization camera 的 `render()`（[Camera sensors](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/camera_sensors.html)）。传感器噪声/真实感建模：IMU 有完整误差族，其余传感器共享 `delay`/`jitter`，并统一提供 `read()`（含不完美）与 `read_ground_truth()`（无噪声）（[Sensors](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/index.html)）；深度相机噪声模型：**未查证**。光追：Luisa RayTracer（已弃用）与 Nyx 路径追踪（[Nyx renderer](https://genesis-world.readthedocs.io/en/latest/user_guide/rendering/nyx_renderer.html)）。
- **C 建模**：Morph 支持 **MJCF（.xml）/ URDF（.urdf、.xacro 自动预处理）/ Mesh（.obj/.stl/.dae/.glb/.gltf）/ USD（.usd/.usda/.usdc/.usdz）** 与基本体、Terrain、Drone；MJCF/URDF 也接受内联 XML 字符串（[Loading assets](https://genesis-world.readthedocs.io/en/latest/user_guide/assets/loading_assets.html)）。**CAD STEP/IGES 导入：未查证**（官方文档未提及）。关节驱动：位置控制为 PD，可设 `set_dofs_kp` / `set_dofs_kv` / `set_dofs_force_range`，并可设 `set_dofs_armature`（反射电机惯量，稳定刚性关节）；MJCF 的 `solref`/`solimp` 会被约束系统读取；关节干摩擦由「非零 friction-loss 系数的 dof 生成一条有界阻力约束」建模（[IK and motion planning](https://genesis-world.readthedocs.io/en/latest/user_guide/robot_control/inverse_kinematics_motion_planning.html)、[Constraint model](https://genesis-world.readthedocs.io/en/latest/user_guide/theory/rigid_solver/constraints.html)、[Domain randomization](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/best_practices/domain_randomization.html)）。摩擦可按 link 缩放（`set_friction_ratio`，范围需落在 [1e-2, 5.0]）。减速器/传动建模：**未查证**（未见 gear/reducer 概念）。软体建模：MPM.Muscle / FEM.Muscle（肌纤维分组 + 方向 + `set_actuation`），以及 `gs.materials.Hybrid`（刚体骨架 + MPM 软皮）（[Soft robots](https://genesis-world.readthedocs.io/en/latest/user_guide/physics/soft_robots.html)）。
- **D 算法生态**：ROS/ROS2 bridge：**未查证**（官方文档未见）。MoveIt：不集成，自带采样规划器 **RRT / RRTConnect**（含 `resolution`/`max_nodes`/`timeout`/`max_retry`/`smooth_path`/`num_waypoints`，可 `with_entity` 规划「手持物体」的路径，也支持批量/`envs_idx` 并行规划；自由关节与球关节不支持）（[Path planning](https://genesis-world.readthedocs.io/en/latest/user_guide/robot_control/path_planning.html)）。RL：官方提供 batched 环境 + 域随机化 + 多 GPU DDP 训练示例，并有 locomotion / drone hover / manipulation 三套训练教程，但**官方 Gym/Gymnasium 封装 API：未查证**（文档未提及，示例为自建环境）（[Policy Training](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/best_practices/domain_randomization.html)、[Multi-GPU](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/multi_gpu.html)）。模仿学习：有「两阶段训练」manipulation 教程（[Examples](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/examples/manipulation.html)）；专门的模仿学习管线：**未查证**。系统辨识 sysid：**未查证**（理论上有可微仿真基础，[Differentiable simulation](https://genesis-world.readthedocs.io/en/latest/user_guide/theory/differentiable_simulation.html)）。
- **E 仿真能力**：大规模并行见 A（单 GPU 数万 env；多 GPU 用「一进程一 GPU」`CUDA_VISIBLE_DEVICES` + `QD_VISIBLE_DEVICE` + `EGL_DEVICE_ID`，或 PyTorch DDP + `torchrun`，不切分单场景）（[Multi-GPU](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/multi_gpu.html)）。域随机化：7 个批量 setter —— `set_friction_ratio`、`set_links_mass`、`set_links_COM`、`set_links_inertia`、`set_dofs_kp`、`set_dofs_kv`、`set_dofs_armature`，均接受 `(n_envs, …)` 张量与 `envs_idx`；每环境质量/COM/惯量与 dof 增益需 `batch_links_info=True` / `batch_dofs_info=True`（[Domain randomization](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/best_practices/domain_randomization.html)）。时间回溯/重放：`scene.start_recording` 写出 `.gstraj` 轨迹文件，`gs.Scene.load_trajectory` 可 seek 与重放；另有 [Checkpoints and simulation state](https://genesis-world.readthedocs.io/en/latest/user_guide/configuration/checkpoints.html)（本报告未逐页核对该页细节：**未查证**）。录制与导出格式：**`.npz`（NPZFile）、`.csv`（CSVFile）、`.mp4`（VideoFile，PyAV 流式）、`.gstraj`（TrajectoryFile）**，另有 PyQtGraph/Matplotlib 实时绘图器（PyQtLinePlot / MPLLinePlot / MPLImagePlot / MPLVectorFieldPlot），支持 `hz` 采样率与后台线程 + 有界缓冲（[Recording data](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/recorders.html)）。可复现性：`gs.init(seed=...)` 同时播种 Python/NumPy/PyTorch/Quadrants；`debug=True` 打开确定性算法；`use_deterministic_algorithms=True` 保证同一机器上 rollout 逐位复现（代价是放弃性能自适应调度）（[Initialization and backends](https://genesis-world.readthedocs.io/en/latest/user_guide/configuration/initialization.html)）。
- **F 界面与交互**：内置 viewer（`show_viewer=True`）+ **ImGui overlay**（`enable_gui=True`）：播放/暂停/单步/重置、实体浏览器（每 dof 关节滑条、自由关节四元数组、visual/collision/wireframe 模式切换）、相机位置与 lookat 滑条、阴影/坐标框/视锥显隐开关、**scene rebuild 按钮**（不重启脚本重跑 `build()`，方便迭代 URDF/MJCF）；可通过 `plugin.register_panel(imgui)` 加自定义面板（[Interactive GUI and debugging](https://genesis-world.readthedocs.io/en/latest/user_guide/interaction/interactive_debugging.html)）。键位绑定（`Keybind`，PRESS/HOLD/RELEASE + 修饰键，自动出现在提示浮层）与 **ViewerPlugin**（鼠标/键盘事件、`update_on_sim_step`、`on_draw` 调试绘制）；内置 **MouseInteractionPlugin 支持鼠标拖拽刚体**（弹簧力或直接设位），`RaycasterViewerPlugin` 提供屏幕坐标→世界射线做点选（[Viewer interaction and plugins](https://genesis-world.readthedocs.io/en/latest/user_guide/interaction/viewer_plugin.html)）。脚本语言：Python（引擎本身用 Python 编写，可直接读/改/嵌入）。图形化模型编辑器：无专用编辑器，仅有 ImGui 的实体浏览器 + scene rebuild（**未查到完整图形建模器**）。**中文界面支持：未查证**（官方文档只有 en / zh-cn 两套**文档**语言，见 [中文文档站](https://genesis-world.readthedocs.io/zh-cn/latest/api_reference/engine/solvers/)；查看器 UI 语言未见说明）。
- **G 可视化**：三条渲染路径（[Introduction](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/what_is_genesis.html)）：**Nyx**（自研 GPU 路径追踪，PBR 材质、HDRI 环境光、**3D Gaussian Splat「光场」资产**与仿真几何同帧渲染、逐像素 object picking、附着相机/多相机/多环境渲染；以 `scene.add_sensor(NyxCameraOptions(...))` 挂载，渲染发生在 `scene.step()` 内，`spp` 与 `render_mode`（如 `FastPathTracer`）调质量/速度）（[Nyx renderer](https://genesis-world.readthedocs.io/en/latest/user_guide/rendering/nyx_renderer.html)）；**Luisa**（DSL 光追，已弃用）；**Pyrender**（光栅化，默认，平台通用）；另有 **Madrona 批量渲染器**（`BatchRendererCameraOptions`，GPU 并行，**仅 CUDA**）。相机传感器后端矩阵与「rasterizer 顺序渲染 / batch renderer 并行渲染」差异见 [Camera sensors](https://genesis-world.readthedocs.io/en/latest/user_guide/sensing/camera_sensors.html)。深度/分割导出：走 visualization camera `render()`（color、depth、segmentation、表面法线四通道）或 `DepthCamera.read_image()`；视频导出：`camera.start_recording()` 与 `VideoFile` recorder；多视口：Nyx 支持多相机与多环境，传统多视口分屏：**未查证**。阴影/反射：由 PBR 路径追踪自然给出；光栅路径的阴影参数：**未查证**。
- **H 部署**：OS 见上；**macOS/Apple M5：官方矩阵给出 GPU 仿真 + CPU 仿真 + 交互查看器 + 无头渲染全 ✅**（[Installation](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/installation.html)），但注意两点限制：**Apple Metal 不支持 double 精度**（`precision="64"` + `gs.metal` 直接报错），且 GPU 后端的确定性只能部分支持（[Initialization and backends](https://genesis-world.readthedocs.io/en/latest/user_guide/configuration/initialization.html)）。无头：支持（关闭 viewer + 可选 EGL/离屏渲染，见 installation 页的 EGL/MESA 排错与 `PYOPENGL_PLATFORM=egl`）。云/远程：官方文档未给托管云服务；多 GPU/DDP 为自建。许可：Apache 2.0（可闭源商用）。
- **I 精度与实时性**：物理步长 `SimOptions(dt=...)`（示例默认 dt=0.01 s），非刚性求解器需 `substeps`（内部子步 = dt/substeps，示例 4e-3 / 10 → 4e-4 s）；固定频率控制环通过每步 `control_dofs_*` + PD 增益实现；精度 `"32"`（默认）/`"64"`（Metal 不可用），整数索引恒为 32 位；`performance_mode=True` 把静态 shape 烘进 kernel，官方称约 **+30% 仿真速度**（代价是场景变化需重新编译，可能数分钟）；默认在终端打印实时仿真 FPS，可用 `ProfilingOptions(show_FPS=False)` 关闭；CPU 单线程性能与具体实时因子：**未查证**（官方提供 `examples/speed_benchmark` 与 [Profiling](https://genesis-world.readthedocs.io/en/latest/user_guide/developers/profiling.html) 页，但本报告未取得具体数值）。数值可复现/确定性：见 E（CPU 完整、GPU 部分；`QD_PERFDISPATCH_FORCE` 可手动钉死实现以复现）（[Initialization and backends](https://genesis-world.readthedocs.io/en/latest/user_guide/configuration/initialization.html)）。
- **J 生态与文档**：资产库：包内自带 `genesis/assets`（相对路径找不到时回落到该目录，例如 `xml/franka_emika_panda/panda.xml`、`urdf/go2/urdf/go2.urdf`）（[Loading assets](https://genesis-world.readthedocs.io/en/latest/user_guide/assets/loading_assets.html)）；另有 USD 导入与网格处理（凸分解/简化）专页。教程：Getting Started（Hello / Control / Parallel / More examples）、物理实体、机器人控制、传感器、渲染、资产、策略训练、理论建模、开发者文档，且**提供完整中文文档站点**（[zh-cn](https://genesis-world.readthedocs.io/zh-cn/latest/)）。插件机制：自定义传感器（Sensor pipeline + Writing a custom sensor）、viewer plugin、Nyx 相机插件、`genesis-world[render]` / `[dev]` / `[usd]` extras、`pyuipc`（IPC，Linux/Windows x86 + NVIDIA GPU）（[PyPI](https://pypi.org/project/genesis-world/)）。更新节奏：极快——1.0.0（2026-05-27）→ 1.4.1（2026-09-12），约 1.2 版本/月（[PyPI Release history](https://pypi.org/project/genesis-world/#history)）。
- **这个软件独有 / 明显强于别人的 3 项**：
  1. **一个场景内统一刚体/FEM/MPM/PBD/SPH/烟雾/IPC 多求解器并带显式 + SAP + IPC 耦合器**，还配可微仿真与自研编译器后端——其余四个都不具备这种「多物理 + 跨后端 + 可微」的组合（[Beyond rigid bodies](https://genesis-world.readthedocs.io/en/latest/user_guide/physics/beyond_rigid_bodies.html)、[Introduction](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/what_is_genesis.html)）。
  2. **Nyx 内置 PBR 路径追踪 + 3D Gaussian Splat 与仿真几何同帧渲染**，并直接以相机传感器形式接入并行/多环境管线（[Nyx renderer](https://genesis-world.readthedocs.io/en/latest/user_guide/rendering/nyx_renderer.html)）。
  3. **官方明确覆盖 Apple Silicon GPU（Metal）仿真 + 交互查看器 + 无头渲染**，在五者中是对 macOS 最友好的（[Installation](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/installation.html)）；同时给出相对 Isaac/MJX 的 10–80× 吞吐声明（[Introduction](https://genesis-world.readthedocs.io/en/latest/user_guide/overview/what_is_genesis.html)）。
- **已知短板 2~3 项**：
  1. **生态集成缺口**：ROS/ROS2、MoveIt、官方 Gymnasium 封装、系统辨识工具链在官方文档中均**未查证到**，需要用户自建；多 GPU 也要自己管进程/DDP（[Path planning](https://genesis-world.readthedocs.io/en/latest/user_guide/robot_control/path_planning.html)、[Multi-GPU](https://genesis-world.readthedocs.io/en/latest/user_guide/policy_training/multi_gpu.html)）。
  2. **工程成熟度与稳定性**：2024-12 起项目，两年内已到 1.4.x，版本节奏极密（0.3.10 → 1.4.1 约 9 个月 25 个版本），文档中仍保留弃用路径（Luisa 光追）、明确标注未解决问题的警告（如 PBD 平布 skinning 退化），且 `performance_mode` 会因场景变化重编译数分钟（[PyPI history](https://pypi.org/project/genesis-world/#history)、[Nyx renderer](https://genesis-world.readthedocs.io/en/latest/user_guide/rendering/nyx_renderer.html)、[Beyond rigid bodies](https://genesis-world.readthedocs.io/en/latest/user_guide/physics/beyond_rigid_bodies.html)）。
  3. **macOS 上的能力天花板**：Metal 后端无 double 精度、GPU 确定性仅部分支持，Nyx 又需额外安装（且当时仍未上 PyPI）（[Initialization and backends](https://genesis-world.readthedocs.io/en/latest/user_guide/configuration/initialization.html)、[Nyx renderer](https://genesis-world.readthedocs.io/en/latest/user_guide/rendering/nyx_renderer.html)）。

- **这个软件独有 / 明显强于别人的 3 项**：

- **一句话定位**：基于 **SAPIEN / PhysX** 的 GPU 并行机器人操作技能仿真 / 基准 / 训练框架，"GPU Parallelized Robotics Simulation and Rendering for Generalizable Embodied AI"（RSS 2025）（[官方文档首页](https://maniskill.readthedocs.io/en/latest/)、[PyPI mani-skill 3.0.1](https://pypi.org/project/mani-skill/)）。

- **H 部署**：安装走 conda / pip（`habitat-lab` 在 PyPI 上，`habitat-sim` 主要在 `aihabitat` conda 频道与 `aihabitat-nightly`；**具体官方安装命令本报告未直接核对，未查证**——官方指向仓库 README 的安装说明）（[PyPI habitat-lab](https://pypi.org/project/habitat-lab/)、[Resource Index](https://aihabitat.org/docs/resource_index/)）。**macOS/Apple M5：基本不可用**（habitat-sim 的 "Only Linux 64 support"，[issue #2358](https://github.com/facebookresearch/habitat-sim/issues/2358)）。无头：可离屏渲染（教程中 `display=False` 走 smoke test 路径，`vut.make_video(..., open_vid=False)`）（[Stereo agent](https://aihabitat.org/docs/habitat-sim/stereo-agent.html)）；且 habitat-lab Demo 明确提醒「一个进程只允许一个 OpenGL 上下文，必须先 close 当前 env 才能建新 env」（[Habitat Lab Demo](https://aihabitat.org/docs/habitat-lab/habitat-lab-demo)）——这是多环境并行的一个重要限制。云/远程：有 Colab（文档中的 profiling Colab、`aihabitat.org/demo` 的 WebGL 演示）（[Resource Index](https://aihabitat.org/docs/resource_index/)、[PyPI habitat-lab](https://pypi.org/project/habitat-lab/)）。许可：habitat-lab MIT；habitat-sim **未查证**。

- **这个软件独有 / 明显强于别人的 3 项**：
  1. **大尺度真实扫描场景与标准化具身基准的生态**：MP3D / Gibson / Replica / HM3D / HM3D-Semantics / HSSD / ReplicaCAD，配套多年 PointNav / Rearrange / OVMM 挑战赛与数据集文档（[Resource Index](https://aihabitat.org/docs/resource_index/)）——其他四者都没有同等级的「真实房屋扫描 + 长期基准」资产体系。
  2. **渲染吞吐**：单线程数千 FPS、单 GPU 多进程 >10,000 FPS（Matterport3D 场景）（[Habitat Sim Docs](https://aihabitat.org/docs/habitat-sim/)）。
  3. **Habitat 3.0 的人形化身 + human-in-the-loop / VR 人机协作**（Social Navigation、Social Rearrangement 两个协作任务），这是五者中唯一系统化做人机协作仿真的（[Habitat 3.0 官网](https://aihabitat.org/habitat3/)）。
- **已知短板 2~3 项**：
  1. **平台限制最严重**：habitat-sim 官方 issue 标题即 "Only Linux 64 support"，Apple M5 macOS 基本无法搭建可用栈（[issue #2358](https://github.com/facebookresearch/habitat-sim/issues/2358)）。
  2. **物理与传感器能力明显弱于其余四者**：无 GPU 并行物理（未查证到）、无通用软体/流体求解器、传感器基本只有 COLOR/DEPTH/SEMANTIC 相机（LiDAR/IMU/力触觉未查证到）、无光追（未查证到）；物理侧只有 VelocityControl + force/torque 这套较薄的接口，且 DYNAMIC 物体用速度控制会被官方警告「预期极大阻尼」（[Interactive Rigid Objects](https://aihabitat.org/docs/habitat-sim/managed-rigid-object-tutorial.html)）。
  3. **文档与更新节奏落后**：Resource Index 中 Articulated Object API 等条目仍标 TODO，教程大量停留在 ECCV 2020 时代，版本节奏为年级（0.3.3 × 2025-01 → 2026-05）；另外「一个进程只能一个 OpenGL 上下文」限制并行进程建模（[Resource Index](https://aihabitat.org/docs/resource_index/)、[Habitat Lab Demo](https://aihabitat.org/docs/habitat-lab/habitat-lab-demo)、[PyPI history](https://pypi.org/project/habitat-lab/#history)）。
