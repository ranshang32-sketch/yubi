## 全局约束

- 标签条宽 **26px**，贴在 **3D 区内侧**（左：`3D.x .. 3D.x+26`；右：`3D右-26 .. 3D右`）；官方 `Options`/`Inspector` 一格都不许盖。
- 展开面板宽 **300**，高 `min(600, 3D高 - 16)`，顶部与 3D 区顶部对齐 +8px。
- 自动收起宽限 **0.8 秒**；钉住时不收；同一时刻只允许一侧"临时展开"，钉住可两侧同时。
- 面板上的文字**只能是 ASCII**（官方 UI 字体无中文字形）；控件 ID 一律用 ASCII 序号，禁止把中文面板名塞进 `##`。
- **不做任何 Dockspace 停靠尝试**（规格 §1.2 已证伪）；不调用 `DockBuilder*`。
- 禁止修改：`软件/插件系统.py`、`软件/启动.py`、`软件/界面桥.py`、`软件/主程序.py` 的【算法装配】区段 —— `软件/零改动自检.py` 对它们算哈希。
- 无 ImGui 上下文时（`--检查`、自检脚本）新增代码**不得调用任何 imgui 函数**（该绑定无上下文时会段错误）。
- 3D 矩形每帧取，不写死像素；首帧尚未拿到时（`configure_docking_layout` 还没被调用）只登记不绘制。
- FPS ≥ 55（沿用既有验收线）；单个面板绘制出错必须被隔离，不影响别人。
- 日志风格沿用仓库习惯：中文、以 `【面板】` 开头、`flush=True`。

## Review Focus

- **首帧几何缺失**：`ux.configure_docking_layout()` 在窗口第一帧之后才有返回值。理性行为：侧栏这一帧不画、不报错、不把 `(0,0,0,0)` 当几何算出负宽窗口。
- **窗口被拉得很小**：3D 宽 < 2×(26+最小面板宽) 时，展开面板不得出现负宽/重叠/把标签条挤出屏幕。
- **`标签条可见 = False` 时【Display】的命运**：Display 是"物理总闸"，必须仍然可见可点（它的可见性不能被侧栏开关连坐）。
- **`_画内容` 缺失或抛异常的面板**：侧栏不得整条崩掉，其余格子照常可点。
- **旧 ini 残留**：`~/.mujoco.ini` 里 `[Window][Workbench]` 与遗留悬浮 DockNode 必须清掉，否则下次启动会飘出一个谁也关不掉的窗口。
- **中文面板名进 ID**：ImGui 的 `##` 解析会歧义（仓库踩过），标签/窗口 ID 必须用 `tab0..tab6` 这类 ASCII 序号。
- **快捷键冲突**：Esc 不得吞官方快捷键；`Ctrl+1..7` 不得与官方 F2/F3/F6/F7、W/A/S/D/Q/E 冲突（F9/F10 已确认可用）。
- **钉住集合里的名字失效**：面板改名/删除后，`输出/面板.json` 里旧名字必须容错忽略，不得让它启动即崩。
- **钉子开关重复点击**：连点图钉 10 次，状态与存档不得错乱，不得产生重复键。
